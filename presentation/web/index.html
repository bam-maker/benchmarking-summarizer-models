Findings

What we learned

BART leads R-1, R-2, R-L, R-Lsum.

Measured on the same 250 articles, using full original highlights.

Fluent summaries can omit the main event.

Content selection can fail with attention and copying.

Processing every source span can still lose important facts.

ROUGE and source-based reading examine different aspects of quality.

15
Engineering lessons

What we tried—and why we changed it

AttemptObservationDecision
Length targets
Early EOS and similar outputs across targets.
Removed the selector. Use natural checkpoint EOS.
Repeated consolidation
Extra passes could over-compress useful content.
Return a fitting merge directly.
400-token hard limit
Treating 400 as capacity caused extra chunking.
Use a guarded 1,024-token app window.
Shared decoding overrides
One shared profile changed native behavior.
Restore model-specific search settings.

How decoding stops

Model Beam Length penalty Repeat handling Initial / hard cap
LSTM 5 Wu 0.9 Block trigrams¹ 100 / 256
Transformer 5 Wu 0.9 Block trigrams¹ 100 / 256
BART 4 2.0 Block trigrams 141 / 512 new
PEGASUS 8 0.8 Native setting: off 127 / 512 new

Natural EOS, deterministic search. Short inputs lower the minimum. Missing EOS permits bounded retries. ¹ OpenNMT exempts the period and sentence tags; summary coverage penalty β = 5 is a beam-search setting.

Appendix / experiments

Why the length selector disappeared

Length targetsShort / Medium / Detailed and percentage goals were implementable. Early stopping and similar outputs made the targets unreliable.
Natural EOSThe demo uses each checkpoint’s search profile. The older length API remains experimental.
ConsolidationFitting articles take one pass. A fitting merge avoids another lossy compression step.
22
Appendix / application

When a merge still exceeds capacity

SplitPack sentence spans within the selected tokenizer’s window. Split oversized sentences and track all original spans.
ReduceGenerate, merge in source order and remove exact repeated sentences. Re-plan an oversized merge.
BoundRequire progress in words and tokens. Work and depth guards stop an unsuccessful request with a clear error.
